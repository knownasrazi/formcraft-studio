## Preview

> Forms crafted, not coded. - built for vibe coders and web developers who ship.

## Stack

- Vite + React + TypeScript
- Tailwind CSS (cream palette)
- Biome for lint and format

## Get started

```bash
git clone https://github.com/knownasrazi/formcraft-studio.git
cd formcraft-studio
bun install
bun run dev
```
formcraft-studio/
  src/
    App.tsx      # app shell
    index.css    # cream tokens
  index.html
  vite.config.ts
  package.json
```

## Cream tokens

Cream, stone, and ink - low contrast, high taste.
