# formcraft-studio — Forms crafted, not coded.

Drag-and-drop form builder - craft forms and export clean HTML or JSON.

---

## Story

We built formcraft-studio because vibe coding needs tools that respect attention. Not another dashboard. Just a surface to work.

## Architecture

```
formcraft-studio/
  src/        — core logic (React + DnD)
  public/     — static assets
  README.md   — you are here
```

- **React + DnD** — the whole thing
- **Cream** — #fdfcfa background, #1a1a1a ink
- **No framework bloat** — you can read every file in 5 minutes

## Install

```bash
git clone https://github.com/knownasrazi/formcraft-studio.git
cd formcraft-studio
bun install
```
